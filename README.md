## 项目简介

大语言模型看似神秘，本质却可以用一句话概括：**它是一台超级"文字接龙"机器** —— 根据上文，不断预测下一个最可能出现的词。

本项目把这条主线拆成 7 个循序渐进的互动实验：从"模型如何读文字"（Token），到"如何表示语义"（Embedding），再到"如何理解上下文"（注意力机制），最后动手玩一个**在浏览器里真实训练出来的微型语言模型**，并亲眼观看模型"从错误中学习"（梯度下降）的全过程。

无需安装任何东西，无需联网，所有实验均在浏览器本地真实运行。

## 每一课都讲了什么

### 01 · Token
模型读不懂整段文字，它看到的全是**最小处理单位 —— Token**（一个汉字、一个英文单词、或单词的一个片段）。输入框中键入内容，页面会实时切分并统计 Token 数，直观展示"为什么中文按字计费、英文按词计费"。

### 02 · Embedding
计算机只认识数字。每个 Token 会被查表转换成一长串数字（向量），这叫 **Embedding**。页面上 22 个词语被投影到二维空间：水果聚在一起、动物聚在一起……悬停任意词可高亮它与最近邻的连线。著名的"国王 − 男人 + 女人 ≈ 王后"向量算术演示，用动画展示 Embedding 如何编码语义方向。

### 03 · 注意力机制
同一个词在不同语境中意思完全不同。模型靠 **Attention** 让每个词"回望"上下文：点击"它"，有的句子里它主要看向"小猫"，有的句子里看向"苹果"——颜色越深代表注意力权重越大。第三句"小明把书包放进柜子，因为它太满了"是故意设计的歧义句，连模型都要在"书包"和"柜子"之间权衡。

### 04 · Transformer
把零件组装起来就是著名的 **Transformer** 架构（GPT、Claude、Gemini 都建立在它之上）。流水线依次展示：输入文本 → Token 切分 → Embedding → 注意力层 ×N → 前馈网络 → 输出概率 → 采样成词。支持手动单步或自动播放。

### 05 · 预测下一个字
本课内置一个**真实的（极简版）语言模型**：页面加载时用一段"小明与小猫"的故事训练出三元语法（trigram）统计模型。输入几个字，它给出下一个字的 Top-5 概率条形图；点"自由续写"，模型按概率采样逐字生成——它只有几百个"参数"，真正的 GPT 有上万亿，但**原理一脉相承**。

### 06 · 训练
模型的知识不是人工写进去的，而是训练出来的：猜 → 错 → 算损失 → 微调参数。小球在损失曲线上沿着"下降最快的方向"滚动（负梯度），就是**梯度下降**算法的直观展示。真实模型可以想象成在上万亿维的山谷里同时滚动无数个小球。

### 07 · 小测验
四道选择题覆盖全部课程要点，答错也能看到解析，满分会出现庆祝语。

## 技术说明

- **单文件架构**：全部内容（结构、样式、逻辑）都在 `index.html` 一个文件里（约 50 KB）
- **零依赖**：不引用任何 CDN、框架或字体文件，完全离线可用
- **真实计算，非预置动画**：
  - 分词器：基于正则的实时切分
  - 词向量图：Canvas 2D 绘制，悬停实时计算最近邻
  - 注意力权重：真实的归一化权重计算与渲染
  - 微型语言模型：页面加载时从内置语料实时统计 trigram 频率，预测与采样均为真实计算
  - 梯度下降：真实的迭代公式 `w ← w − η·∇L(w)`
- **响应式布局**：适配桌面与移动端
- **隐私**：无任何网络请求与数据上报
