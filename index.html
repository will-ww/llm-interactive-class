大语言模型
到底是怎么工作的？

大模型看似神秘，本质却可以用一句话概括：它是一台超级"文字接龙"机器—— 根据上文，不断预测下一个最可能出现的词。本课堂用 6 个可以亲手操作的实验， 带你一步步看清它背后的原理。

开始第一课 直接动手玩
LESSON 01

01Token：大模型的"字母表"

模型读不懂整段文字，它看到的全是最小处理单位 —— Token。 一个 Token 可能是一个汉字、一个英文单词，或单词的一个片段。 模型的一切计算，都建立在这些小块之上。

动手试试：输入文字，实时看它被切成多少个 Token

Token 总数 0 字符数 0

观察：一个汉字通常就是 1 个 Token（颜色块）；一个英文单词往往会被切成 2~3 个片段。 这就是为什么处理英文时"按词计费"，而处理中文时"按字计费"。

LESSON 02

02Embedding：给每个词一个"坐标"

计算机只认识数字。每个 Token 都会被查表转换成一长串数字（向量）， 这叫 Embedding（嵌入）。语义相近的词，坐标也相近—— 把鼠标悬停在图上任意词上，看看谁离它最近。

悬停某个词，看看它的"邻居"是谁。

LESSON 03

03注意力机制：词语之间的"互相打量"

同一个词在不同语境中意思完全不同（想想"苹果"是水果还是公司？）。 模型靠 Attention（注意力） 让每个词去"打量"上下文中的其他词， 颜色越深，表示关注得越多。点击句子中的任意词试试。

↑ 点击任意词语，观察它"回望"了谁（颜色越深 = 注意力权重越大）

LESSON 06

06训练：从错误中学习

模型的知识不是人工写进去的，而是训练出来的：先随便猜 → 对比正确答案 → 计算损失（错得有多离谱）→ 微调参数让损失变小。这个过程叫梯度下降，就像小球滚下山谷。
